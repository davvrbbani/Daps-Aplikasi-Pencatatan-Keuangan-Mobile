# Daps Aplikasi Pencatatan Keuangan Mobile 📱💰

Aplikasi modern, cepat, dan cerdas untuk mencatat dan memonitor keuangan pribadi Anda! Daps Pencatatan Keuangan dirancang untuk memberikan kemudahan dalam melacak pengeluaran dan pemasukan harian dengan antarmuka yang bersih dan interaktif.

## ✨ Fitur Utama

- **Pencatatan Cepat & Mudah**: Masukkan transaksi harian Anda hanya dengan beberapa ketukan.
- **Kategorisasi Transaksi**: Kelompokkan pengeluaran dan pemasukan Anda ke dalam berbagai kategori.
- **Auto-Update Seamless**: Didukung oleh teknologi [Shorebird](https://shorebird.dev/), aplikasi ini akan menerima pembaruan (*patch*) secara otomatis di *background* tanpa perlu mengunduh versi baru dari awal! Cukup tutup dan buka aplikasi, dan fitur terbaru sudah terpasang.
- **Desain Modern**: Antarmuka berbasis Material Design 3 yang responsif dan memanjakan mata.

## 📥 Download Aplikasi (APK)

Untuk mencoba aplikasi ini, Anda dapat mengunduh langsung file APK rilis resmi pada repositori ini:

1. Unduh file `app-release.apk` yang tersedia di direktori utama repositori ini.
2. Pindahkan ke perangkat Android Anda.
3. Izinkan penginstalan dari "Sumber Tidak Dikenal" (*Unknown Sources*).
4. Instal dan nikmati!

*(Aplikasi sudah dilengkapi dengan kapabilitas Auto-Update).*
