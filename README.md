# Daps Aplikasi Pencatatan Keuangan Mobile 📱💰

**Daps Pencatatan Keuangan** adalah aplikasi *mobile* modern berbasis AI dan *Cloud* yang dirancang khusus untuk membantu Anda mengelola, melacak, dan merencanakan keuangan pribadi Anda dengan cerdas dan mudah. Aplikasi ini tidak hanya sekadar tempat mencatat, tapi juga menjadi asisten finansial Anda.

## 🎯 Gambaran Umum Aplikasi
Mengatur uang seringkali membingungkan. Daps hadir untuk menyelesaikan masalah tersebut dengan menyediakan antarmuka interaktif yang langsung menunjukkan *insight* kemana uang Anda pergi. Anda dapat memantau sisa saldo, membedah pengeluaran berdasarkan kategori, serta mengontrol anggaran bulan demi bulan—semuanya tersinkronisasi dengan aman secara *real-time*.

## ✨ Fitur Utama

- 📊 **Dashboard & Statistik Interaktif**: Lihat ringkasan saldo, pemasukan, dan pengeluaran Anda dalam bentuk visualisasi yang mudah dimengerti.
- 💸 **Pencatatan Transaksi Detail**: Catat pengeluaran dan pemasukan dengan sangat detail, didukung pemilihan kategori dan kalender khusus.
- 🎯 **Target Anggaran (Budgets)**: Pasang batas pengeluaran untuk tiap kategori (misal: Makanan, Transportasi) agar dompet Anda tidak kebobolan!
- ☁️ **Cloud Database & Sinkronisasi**: Seluruh data transaksi tersimpan dengan aman berkat integrasi teknologi Supabase, sehingga data tidak akan hilang meski Anda mengganti *device*.
- 🤖 **Fitur Berbasis AI**: Membantu memberikan insight pintar tentang kondisi dan kesehatan keuangan Anda.
- 🎨 **Desain Material & Animasi Mulus**: Dibangun dengan Flutter yang responsif dan mengedepankan pengalaman visual *glassmorphism* modern.
- ⚡ **Auto-Update (Over-The-Air)**: Didukung oleh teknologi *Shorebird*, fitur terbaru dan perbaikan sistem akan diunduh dan dipasang secara otomatis di latar belakang tanpa Anda perlu mengunduh ulang APK! Cukup buka aplikasinya dan nikmati fitur terbarunya.

## 📥 Download & Cara Install (APK)

Untuk mencoba aplikasi ini, Anda dapat mengunduh langsung file APK rilis resmi pada repositori ini:

1. Klik dan unduh file **`app-release.apk`** yang tersedia di repositori ini.
2. Pindahkan ke perangkat Android Anda.
3. Saat menginstal, pastikan Anda memberikan izin untuk menginstal dari "Sumber Tidak Dikenal" (*Install Unknown Apps*).
4. Instal dan mulai kelola keuangan Anda!

*(Tidak perlu khawatir soal update, aplikasi ini akan mengupdate dirinya sendiri jika ada versi kode yang baru).*
